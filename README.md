# Jeevika Kiran — Portfolio

A responsive portfolio built with Next.js, React, TypeScript and Tailwind CSS.

## Local development

Requires Node.js 18.18 or newer.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validation

```bash
npm run lint
npm run type-check
npm run build
```

## Environment variables

- `RESEND_API_KEY` enables contact-form delivery.
- `NEXT_PUBLIC_GA_ID` optionally enables Google Analytics.

The site can be deployed to any platform that supports Next.js 15.
